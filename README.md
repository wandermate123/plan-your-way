# Wandermate — Instant Travel Quotation (MVP)

This is a self-serve quotation web app for your travel agency.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Pricing

Rates are stored in `data/pricing.json`. Edit that file and redeploy (or restart the dev server) to update quoted prices.
