# Wandermate — Instant Travel Quotation (MVP)

This is a self-serve quotation web app for your travel agency.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Admin pricing

- Admin page: `http://localhost:3000/admin`
- Default token: `changeme`
- Set your own token (recommended):

```bash
ADMIN_TOKEN="your-strong-token" npm run dev
```

Pricing is stored in `data/pricing.json`.
